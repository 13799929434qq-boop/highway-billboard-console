- 前端：React 19、TypeScript、Vite、Tailwind CSS、shadcn/ui、React Router、Zustand、TanStack Query、Axios、React Hook Form、Zod、Lucide React；图表 ECharts。

## 四类业务闭环

1. 运营档案：路段→地区→运营单位建档 → 广告牌及三桩号/土地/照片 → 证件维护 → 合同关联检查 → 移位/拆除留痕。删除需检查引用，拆除不清除历史。
2. 合同财务：客户建档/黑名单 → 合同草稿与多牌多年度租金 → 合规及占用冲突校验 → 生效 → 年度应收 → 收款入账（可待分配）→ 分配核销 → 欠款查询。发票和支出独立记录，开票不自动核销应收。
3. 系统管理：账号 → 角色权限 → 数据范围 → 字典维护 → 操作日志。领导角色只读，权限最终由服务端执行。
4. 领导：经营总览 → 数量/执行/实收/应收四报表 → 只读资产/合同/应收详情 → 导出。不增加录入、审批、核销操作。

## 仍需业务确认的规则

- 移位、拆除是否审批，以及审批角色和顺序；原型展示校验和保存草稿，不擅自赋予领导审批职责。
- 客户进入黑名单对既有合同的处理，不能默认自动解除。
- 多账单收款分配的优先顺序；原型使用明确手工选择，不假定自动先进先出。
- 解除后的未到期应收、退款、保证金及更正处理，需业务确认，不能一键清零或删除历史。
- 照片最少张数、各字典最终选项、提醒提前天数、可出租判断口径。
